# Jenkins AWS EC2 Task

## Overview

This project demonstrates the basic setup and usage of Jenkins on an AWS EC2 instance.

## Environment

- AWS EC2
- Ubuntu Linux
- Java 21
- Jenkins
- Git
- GitHub

## Tasks Completed

1. Launched an AWS EC2 instance.
2. Installed Java 21.
3. Installed Jenkins.
4. Started and enabled Jenkins as a system service.
5. Accessed Jenkins through the web interface.
6. Created a Jenkins user.
7. Created a Freestyle project.
8. Executed a successful Jenkins build.
9. Created a Jenkins Pipeline project.
10. Executed a successful Pipeline.
11. Stored the Jenkinsfile in GitHub.
12. Added screenshots as project evidence.

## Jenkins Pipeline

The pipeline contains the following stages:

- Build
- Test
- Deploy
